These SCORM 1.2 content packaging and metadata schema files are included at the
root of generated packages because the manifest references their filenames.
Keep the original schema comments and relative import filenames intact.

The files are from the SCORM 1.2 XML Schema Definition bundle linked by
[SCORM.com](https://scorm.com/scorm-explained/technical-scorm/content-packaging/xml-schema-definition-files/).
