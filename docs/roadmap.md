# Delivery roadmap

Work one phase at a time; stop after the requested phase.

Requested required-media progress fix: required native video/audio blocks must play continuously from the beginning to the natural end before recording completion. Shared browser playback coverage prevents forward seeking from unlocking existing lesson/Continue gates in standard lessons, slides and static HTML/SCORM; rewind and completed review remain available. The requested presentation progress extension puts ten verified duration checkpoints and required action progress in menu circles starting at zero, with source-bound partial resume in browser and LMS storage. It adds no completion indicators to media players and leaves standard-mode reading and completion calculations unchanged. This fixes the existing media/progress slice without expanding other phases.

Requested dashboard mobile responsiveness fix: restore folder-tree/workspace access below the desktop breakpoint through the shared navigation modal, keep long course/folder text and card actions inside responsive grids, wrap navbar/workspace/filter controls, and match loading layouts. Existing ownership, permissions, routing, creation, and course-setting handlers remain in use. This fixes the completed dashboard slice without adding another application or expanding unfinished phases.

1. **Foundation:** Next.js, TypeScript, MongoDB/Mongoose, Auth.js, shared schemas, UI/tooling, tests, and static export build boundary.
2. **Dashboard and folders:** folder tree, course CRUD, search, breadcrumbs, and organization.
3. **Lesson editor:** sections, lessons, block editing, ordering, autosave, and persistence.
4. **Core blocks and media:** content rendering, media library, validation, and storage.
5. **HTML export:** standalone learner experience, navigation, progress, preview, and HTML5 publishing.
6. **SCORM 1.2:** validated snapshot, manifest and schema files, shared static export runtime, LMS runtime, resume/completion tracking, media packaging, and focused tests.
7. **Interactive blocks:** learner-answerable knowledge checks, author-configurable answer feedback, rating surveys, shared preview/export rendering, and focused tests.
8. **Quizzes and assessments:** author-set passing scores, graded attempts and retry, persisted assessment results, course navigation gating, SCORM score reporting, and focused tests.
9. **Themes and branding:** saved course palettes, custom brand and accent colors, typography options, themed course and lesson previews, and export parity.
10. Templates.
11. **Advanced navigation:** searchable and collapsible learner course outline, per-section completion summaries, and course-level free, sequential, or restricted lesson progression across preview and standalone export.
12. **Additional publishing formats:** downloadable PDF course handout with owner-scoped images and learner-safe quiz prompts.
13. **Team collaboration:** shared workspaces, owner/admin/editor/viewer roles, email-bound copyable invitations, and workspace-scoped courses and folders.
14. **AI generation:** prompt and document ingestion, structured course drafts using existing blocks, optional generated images, and author review/apply.
15. Production hardening.

Current status: Phases 1 through 9, 11, 12, and 13 are complete. Phase 14 AI generation remains in progress by request; Phase 10 is unstarted.

The requested presentation header/footer styling extension adds footer Transparent/Color/Image backgrounds, owned background images, positioning and overlay colors, plus independent header top/bottom borders with shared color and width controls. Existing footer colors and the header's top accent stripe remain the defaults. Validation, course persistence, asset ownership, undo/redo, thumbnails, preview, and static HTML/SCORM use the shared renderer and data contracts within the existing presentation slice.

The requested presentation text slice adds supported font families, superscript/subscript, and a shared equation dialog with LaTeX source, live preview, syntax validation, and six formula templates. Inline equations work in text/title editors; body text also supports display equations. Existing text blocks carry the equation nodes through drafts, undo, clipboard, popup Apply/Cancel, learner preview, thumbnails, and offline HTML/SCORM with bundled fonts. PDF handouts preserve source text rather than typesetting formulas. Advanced spacing, a general symbol picker, OCR, and typeset math PDF output remain outside this initial slice.

The requested Faster Presentation Editing slice adds multi-selection, persistent flat groups, shared movement and proportional corner resizing, selection/canvas alignment, equal spacing, and group-aware lock/hide/layer controls in main and popup editors. Bulk clipboard operations remain compatible with older payloads and preserve ownership, cover, nesting, object-count, save, and undo boundaries. Group rotation, nested groups, bulk styling, reusable templates, and narration timelines remain outside this slice.

The requested flip-card presentation extension creates three cards in new main-slide and popup objects, adds direct front/back editing and a nearby card toolbar, individual duplication/deletion and pointer/touch/keyboard ordering, shared colors with per-card overrides, and responsive Auto/Custom grids with padding, gaps, alignment and radius controls. Shared rendering preserves thumbnails, preview and offline HTML/SCORM. This extends the existing presentation slice without expanding other phases.

The requested presentation media overlay extension adds independent solid/gradient overlay colors to image backgrounds, headers, and covers, plus color and opacity controls for plain image and video objects. Existing save, ownership, media replacement, thumbnail, preview, and static export paths retain these settings without adding another application or expanding other phases.

The requested presentation transform controls give every block a move handle, eight resize points, and rotation in main slides and popup mini slides. The requested presentation object clipboard extension adds native Ctrl+C/Ctrl+V and Command+C/Command+V on the same slide or another slide in the course, including popup mini slides. The requested presentation alignment and appearance extension adds canvas edge and center snapping, header/footer guides, explicit alignment buttons, a snap toggle and Alt bypass in main and popup slides. Shared painting keeps thumbnails, preview and static HTML/SCORM consistent. Placement and appearance use existing undo/redo and autosave. The requested presentation toolbar refinement places Snap to guides in the canvas top bar and adds a navbar icon for pending edits, saving, saved, invalid title, failure and conflict states. The requested Hanging Rope Cards interaction adds editable cards on elastic, swaying ropes with a glowing reveal target for each card. Per-card progress, accessibility/reduced motion, static HTML, SCORM 1.2/2004, nested media ownership/packaging, duplication and handouts follow existing architecture. This requested block extension does not expand other unfinished phases or introduce another application.

The requested reusable Physics Interaction System introduces a browser-only spring/lifecycle controller and the first `peelToReveal` block. Standard and Presentation modes share pointer-driven curled SVG paper, resistance, damped spring recovery, threshold completion, animated click/tap, keyboard and reduced-motion activation. Authors edit paper materials, appearance, physics, triggers, replay, and replaceable formatted text/media through the existing picker, slide toolbar, media library, undo/redo and autosave. An explicit leaf-content schema prevents recursive physics nesting and bounds reveal content. Completed reveals integrate with optional/required gates, browser resume, static HTML, SCORM 1.2/2004 and the PDF handout. Existing owner-scoped persistence and recursive media packaging are reused. This requested interaction extension adds no second application or export service and does not expand unfinished template or generation phases.

The requested presentation settings refinement puts content first, then media source and position/size, with navigation/progress last. The requested presentation animation extension adds Slide up (default, 1000 ms), Fade in, Zoom in, Slide down/left/right, and None to every main-slide and popup block. Presentation interaction buttons support a course-owned image or 24 preset icons, a fixed pixel button size (20px by default), nine alignments inside the object box, independent solid/gradient colors, a radar toggle, and an action that opens either a selected block from the same lesson or an editable popup mini slide. Popup slides support every validated content block type, including nested interaction buttons, through the regular slide insertion toolbar, More blocks picker, and shared object settings card. They retain inline text editing, pixel geometry, draggable layers, duplication/deletion, media selection, crops, and playback settings. Each mini slide retains its 20-object limit, and validation bounds nested popups to eight levels. Popup width and height accept unfinished numeric drafts while typing, then restore or bound them on blur. Applying commits one parent edit with undo/redo and autosave; Cancel discards the local draft. The shared lesson renderer handles popup activities and Continue gates using local progress; opening the parent remains its course progress task. Nested buttons remap local targets during learner rendering and duplication. Nested native dialogs handle Escape independently. Media ownership checks and recursive offline packaging cover nested galleries, flip cards, graphics, instructions, files, and inline asset references. Authors configure popup dimensions, colors and fade/zoom/slide animation; reduced-motion preferences disable animation. Native modal popups render outside the scaled slide while retaining the course theme and fullscreen container, fit narrow viewports, and pause/unmount their media on close or slide change. Opening a configured button records its required activity; optional or unavailable buttons do not block navigation. Duplicating lessons/sections remaps linked block IDs, and deleting a target clears its links. Save validation checks every trigger and nested media asset for ready ownership in the current course; existing recursive HTML/SCORM packaging includes and remaps those assets. Audio instruction blocks expose autoplay on slide entry and optional icon/text controls for manual playback when a browser blocks automatic sound.

It reuses ordered lessons as slides and existing blocks, with a fitted canvas defaulting to 16:9, course-wide Widescreen/Standard/Square/custom pixel sizes and landscape/portrait orientation in Master slide settings, free object dragging and resizing, visible block content settings, a selectable layer list, Master slide/Object block/Cover page inspector tabs with compact grids, labeled icons, per-section toggles and per-tab Show all/Hide all actions, configurable header colors and course-owned background images, shared square color swatches and hex inputs with validated two-stop gradient controls across object and master colors, per-object Required for progress switches for restricted activity gates and optional Continue blocks, master themes, a responsive panel of actual slide thumbnails with pointer/touch and keyboard reordering, autosave and undo, per-slide Delete buttons and an Add slide action, and dedicated presentation preview and static learner shell. Each slide has a setting to show or hide its Previous, Next, and Restart buttons independently of footer visibility; enabled navigation floats over slides with hidden footers. The editor has Previous, Restart, and Next controls in the shared footer on cover, content, and quiz slides by default, and the canvas workspace has a light-gray surround. Its wider inspector accompanies Fit and 25–200% canvas zoom controls; zoom persists across slide selection and oversized canvases scroll within the workspace. All slide blocks can snap to the footer edge or use Align to footer. Uploaded video/audio has autoplay and player-control settings, with the saved player-control setting respected before and after completion and a footer Restart slide action that preserves progress. The full-width footer contains Previous/Next and icon-only Restart controls, chat tips with arrows aimed at each control, configurable height/text size/spacing, shared or per-button gradient colors and Outline/Solid/Soft/Modern/Glass/3D raised presets with size and shape controls. It supports text, up to twelve ordered course-owned logos, background/text colors, and a configurable top border across editor, preview, and offline export. Master backgrounds support course-owned images with crop/overlay settings and six free built-in abstract vector designs; the same backgrounds appear in preview and offline exports. Authors can edit headings, body text, and statement text directly inside slide objects, format the focused text from the inspector, and use separate handles to move or resize objects. Text boxes support horizontal and vertical alignment, including centering text within the box. Plain images and uploaded videos start at their intrinsic aspect ratio and resize proportionally through the corner handle, width, height, or scale controls. A Crop inspector adds drag/keyboard selection, corner resizing, common aspect ratios, pixel fields, Apply/Cancel/Reset, and undoable source-preserving crops. Cropped proportions and video controls remain consistent across editor, thumbnails, preview, and static export. All presentation blocks fit overflowing content within their boxes; flip-card grids use compact responsive layouts so larger card collections remain visible, with matching behavior in editor, preview, and standalone export. Every presentation block defaults to a transparent background and supports its own color and opacity through the inspector, with the same fill in preview and static learner exports. Authors can insert an image cover as the first slide, edit its course title, subtitle, lesson label, image, and Start button, and retain existing slide content. Cover layout supports nine grouped positions, independent title/subtitle/Start positions with pixel offsets, optional course-owned Audio instruction objects with autoplay and icon/text display toggles, and editable first-visit welcome notices. Master settings add optional customizable first-visit navigation tips anchored to Next, Previous, and Restart, with replay help in editor, preview, and static export. Instruction blocks pause when leaving their slide and offer manual playback through their visible icon/text control when browser autoplay is blocked; guide and notice state stay separate from learner completion. The rest of Phase 10 remains unstarted.
