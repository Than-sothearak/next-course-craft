# Delivery roadmap

Work one phase at a time; stop after the requested phase.

1. **Foundation:** Next.js, TypeScript, MongoDB/Mongoose, Auth.js, shared schemas, UI/tooling, tests, and static export build boundary.
2. **Dashboard and folders:** folder tree, course CRUD, search, breadcrumbs, and organization.
3. **Lesson editor:** sections, lessons, block editing, ordering, autosave, and persistence.
4. **Core blocks and media:** content rendering, media library, validation, and storage.
5. **HTML export:** standalone learner experience, navigation, progress, preview, and HTML5 publishing.
6. **SCORM 1.2:** validated snapshot, manifest and schema files, shared static export runtime, LMS runtime, resume/completion tracking, media packaging, and focused tests.
7. **Interactive blocks:** learner-answerable knowledge checks, author-configurable answer feedback, rating surveys, shared preview/export rendering, and focused tests.
8. **Quizzes and assessments:** author-set passing scores, graded attempts and retry, persisted assessment results, course navigation gating, SCORM score reporting, and focused tests.
9. **Themes and branding:** saved course palettes, custom brand and accent colors, typography options, themed course and lesson previews, and export parity.
10. Templates.
11. **Advanced navigation:** searchable and collapsible learner course outline, per-section completion summaries, and course-level free, sequential, or restricted lesson progression across preview and standalone export.
12. **Additional publishing formats:** downloadable PDF course handout with owner-scoped images and learner-safe quiz prompts.
13. **Team collaboration:** shared workspaces, owner/admin/editor/viewer roles, email-bound copyable invitations, and workspace-scoped courses and folders.
14. **AI generation:** prompt and document ingestion, structured course drafts using existing blocks, optional generated images, and author review/apply.
15. Production hardening.

Current status: Phases 1 through 9, 11, 12, and 13 are complete. Phase 14 AI generation remains in progress by request; Phase 10 is unstarted.

The requested slide interactive image extension adds independent point colors, direct canvas point dragging and popup editing. Free map choices have been removed from interactive image settings; new objects use an image placeholder for authors to replace with their own image. Existing saved map backgrounds remain compatible. Point drags commit on release with undo support. These settings retain the existing draft save path and render in preview and static learner exports.


Presentation interaction buttons support a course-owned image or 24 preset icons, a fixed pixel button size (80px by default), nine alignments inside the object box, independent solid/gradient colors, a radar toggle, and an action that opens either a selected block from the same lesson or an editable popup mini slide. Popup slides reuse validated text/image/video/audio objects, inline text editing, pixel geometry controls, canvas dragging/resizing, media selection and playback settings. Authors configure popup dimensions, colors and fade/zoom/slide animation; reduced-motion preferences disable animation. Native modal popups render outside the scaled slide while retaining the course theme and fullscreen container, fit narrow viewports, and pause/unmount their media on close or slide change. Opening a configured button records its required activity; optional or unavailable buttons do not block navigation. Duplicating lessons/sections remaps linked block IDs, and deleting a target clears its links. Save validation checks every trigger and nested media asset for ready ownership in the current course; existing recursive HTML/SCORM packaging includes and remaps those assets. Audio instruction blocks expose autoplay on slide entry and optional icon/text controls for manual playback when a browser blocks automatic sound.

Requested Phase 15 administration scope is implemented: account approval, immutable Super Admin bootstrap, constrained platform RBAC, administration dashboards, explicit course assignments, ownership transfer, current database authorization, transactional audit logs, and focused security/regression verification. Deployment requires the explicit migration and bootstrap steps in `docs/admin-operations.md`. Other production hardening remains outside this administration scope.

The requested administration extension adds Super Admin workspace listings, details, name updates, and audited deletion of empty workspaces. Existing courses (including recently deleted courses) and folders block workspace deletion.

Requested Phase 15 Media Storage scope extends the existing administration and media systems with Super Admin provider switching, private persistent local storage, legacy S3 compatibility, and provider-independent HTML/SCORM/PDF publishing. No other unfinished phase is included.

Requested Phase 15 verification scope adds a reproducible full test baseline with transactional MongoDB, production browser smoke tests, CI checks, focused AI/editor module splits, and an isolated workload for 100 concurrent authors browsing and editing. Results and remaining performance limits are recorded in `docs/verification-baseline.md`. This scope does not complete all production hardening or the unfinished generation/template phases.

Requested Phase 10 slide template slice: course creation offers a Slide interactive presentation alongside the standard course. It reuses ordered lessons as slides and existing blocks, with a fitted canvas defaulting to 16:9, course-wide Widescreen/Standard/Square/custom pixel sizes and landscape/portrait orientation in Master slide settings, free object dragging and resizing, visible block content settings, a selectable layer list, Master slide/Object block/Cover page inspector tabs with compact grids, labeled icons, per-section toggles and per-tab Show all/Hide all actions, configurable header colors and course-owned background images, shared square color swatches and hex inputs with validated two-stop gradient controls across object and master colors, per-object Required for progress switches for restricted activity gates and optional Continue blocks, master themes, a responsive panel of actual slide thumbnails with pointer/touch and keyboard reordering, autosave and undo, per-slide Delete buttons and an Add slide action, and dedicated presentation preview and static learner shell. The editor has Previous, Restart, and Next controls in the shared footer on cover, content, and quiz slides, and the canvas workspace has a light-gray surround. Its wider inspector accompanies Fit and 25–200% canvas zoom controls; zoom persists across slide selection and oversized canvases scroll within the workspace. All slide blocks can snap to the footer edge or use Align to footer. Uploaded video/audio has autoplay and player-control settings, with the saved player-control setting respected before and after completion and a footer Restart slide action that preserves progress. The full-width footer contains Previous/Next and icon-only Restart controls, chat tips with arrows aimed at each control, configurable height/text size/spacing, shared or per-button gradient colors and Outline/Solid/Soft/Modern/Glass/3D raised presets with size and shape controls. It supports text, up to twelve ordered course-owned logos, background/text colors, and a configurable top border across editor, preview, and offline export. Master backgrounds support course-owned images with crop/overlay settings and six free built-in abstract vector designs; the same backgrounds appear in preview and offline exports. Authors can edit headings, body text, and statement text directly inside slide objects, format the focused text from the inspector, and use separate handles to move or resize objects. Text boxes support horizontal and vertical alignment, including centering text within the box. Plain images and uploaded videos start at their intrinsic aspect ratio and resize proportionally through the corner handle, width, height, or scale controls. A Crop inspector adds drag/keyboard selection, corner resizing, common aspect ratios, pixel fields, Apply/Cancel/Reset, and undoable source-preserving crops. Cropped proportions and video controls remain consistent across editor, thumbnails, preview, and static export. All presentation blocks fit overflowing content within their boxes; flip-card grids use compact responsive layouts so larger card collections remain visible, with matching behavior in editor, preview, and standalone export. Every presentation block defaults to a transparent background and supports its own color and opacity through the inspector, with the same fill in preview and static learner exports. Authors can insert an image cover as the first slide, edit its course title, subtitle, lesson label, image, and Start button, and retain existing slide content. Cover layout supports nine grouped positions, independent title/subtitle/Start positions with pixel offsets, optional course-owned Audio instruction objects with autoplay and icon/text display toggles, and editable first-visit welcome notices. Master settings add optional customizable first-visit navigation tips anchored to Next, Previous, and Restart, with replay help in editor, preview, and static export. Instruction blocks pause when leaving their slide and offer manual playback through their visible icon/text control when browser autoplay is blocked; guide and notice state stay separate from learner completion. The rest of Phase 10 remains unstarted.


Audio instruction is a separate optional content block on presentation covers and content slides, with a course-owned audio file, autoplay on slide entry, editable text, independent Show icon/Show text toggles, and solid/gradient colors. Cover settings now contain only the welcome notice, alongside the existing cover appearance and layout controls. Presentation objects on cover and ordinary slides use full-canvas geometry so they can move over header or footer decoration; older object positions convert on load. Only audio instruction objects are permitted on covers, keeping other lesson content visible on content slides. Both slide surfaces share editing, layers, moving/resizing, deletion, undo, saving, thumbnails, preview and static HTML/SCORM rendering. Instruction audio never autoplays in authoring or thumbnails, pauses when leaving the slide or removing/replacing the object, and supports footer Restart. Existing cover instruction files are converted to optional instruction blocks on load, preserving the file, notice and automatic/manual preference; legacy cover/Start triggers map to autoplay on entry. The old cover audio source is cleared in the returned draft to prevent duplicate playback and is persisted through the normal save path. Raw legacy learner data remains backward compatible. Instruction assets use the existing ownership-scoped audio validation and recursive export packaging.
